# Business Case, Input Checklist

Gather these before running [`business-case-prompt.md`](business-case-prompt.md). You don't
need everything, but the items marked **(critical)** should be present, otherwise the AI
will pause and ask you for them before drafting. The more you provide, the stronger and
faster the first draft.

> Tip: You can paste this checklist under the prompt and just fill in answers inline.

## 1. Basics
- [ ] Project / initiative name
- [ ] One-line description
- [ ] Initiative type: software/IT · process improvement · product/R&D · other
- [ ] Sponsor, author, and today's date
- [ ] Version / status (Draft, For Review, Approved)

## 2. Problem & goal **(critical)**
- [ ] What problem or opportunity are we addressing?
- [ ] How big is it? (magnitude, frequency, who's affected)
- [ ] What's the **cost of doing nothing**?
- [ ] What does success look like, the goal in one sentence?

## 3. Proposed solution & scope **(critical: solution)**
- [ ] What will we actually do?
- [ ] What's **in scope** vs **out of scope**?
- [ ] Other options you considered (so the AI can compare them fairly)

## 4. Costs **(critical: at least rough figures)**
- [ ] One-time / implementation costs (CapEx)
- [ ] Recurring / run costs per year (OpEx: licenses, support, headcount, etc.)
- [ ] Internal effort (people, hours, roles)

## 5. Benefits **(critical: at least rough figures or a way to quantify)**
- [ ] Quantifiable benefits (cost savings, revenue, time saved, quality/defect reduction)
- [ ] How each benefit is calculated or estimated
- [ ] Qualitative / strategic benefits (customer experience, risk reduction, capability)

## 6. Financial assumptions **(critical: horizon + discount rate)**
- [ ] Time horizon for the analysis (e.g., 3 or 5 years)
- [ ] Discount / hurdle rate to use (ask finance if unsure)
- [ ] Any known constraints on budget or capital

## 7. Strategic fit
- [ ] Which strategic priority / goal does this support? (`[STRATEGIC PRIORITY]`)
- [ ] How does it advance the **Veralto Enterprise System (VES)**?

## 8. Risks
- [ ] Top risks (technical, adoption, market, execution)
- [ ] Rough likelihood and impact of each
- [ ] Any mitigations already in mind

## 9. Implementation
- [ ] High-level phases / milestones
- [ ] Target start and key dates
- [ ] Owners / teams involved
- [ ] Dependencies (systems, teams, approvals) and hard constraints

## 10. Success metrics
- [ ] The 3-5 KPIs that prove this worked
- [ ] A target for each, and how/when you'll measure it

## 11. Branding (optional)
- [ ] Exact Hach/Veralto brand hex codes (if you want to override the defaults)
